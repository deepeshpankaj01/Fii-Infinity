## ⚡ Highlights

- **🛩️ Stratospheric Sky Entry**: Golden hour cloudscape with real-time mouse parallax & dynamic telemetry HUD.
- **🎴 Zero-Gravity Bento Orbit**: 3D gyroscopic tilt cards with specular reflections, filtering, and deep-dive inspection modals.
- **🏎️ Valkyrie Aero Configurator**: Real-time canvas aerodynamic wind tunnel simulation, bespoke finishes (Titanium, Forged Carbon, Champagne Gold, Nebula), dynamic environments, and X-Ray blueprint mode.
- **🪐 Anti-Gravity Sanctuary**: Inverted particle physics engine ($-1.0G$) & bespoke private allocation reservation flow.
- **🎧 Procedural Web Audio**: Zero-asset spatial synthesizer with real-time sub-bass drone, wind filters, and interactive harmonic chimes.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS & custom glassmorphism / metallic gradients
- **3D & Canvas**: Three.js WebGL starfield & HTML5 2D Canvas physics
- **Audio**: Browser Web Audio API (procedural synthesis)
- **Icons**: Lucide React

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

---

## 🎮 Key Controls

- **Mouse / Trackpad**: 3D card tilt, cursor stardust trail, and depth parallax.
- **Audio Toggle**: Toggle procedural sound via the floating bottom dock.
- **Configurator**: Toggle wind streamlines, swap atmospheric environments, engage X-Ray mode, and click telemetry hotspots.
