## ⚡ Overview

**FII-INFINITY** is an ultra-luxury, avant-garde digital showcase and interactive configurator engineered for high-performance automotive connoisseurs. Blending futuristic glassmorphism, procedural canvas simulations, WebGL starfields, and real-time Web Audio synthesis, the platform delivers an unprecedented spatial web journey.

From soaring through stratospheric golden-hour cloudscapes at 12,400 meters to configuring active aerodynamics in wind tunnels and inverting gravity in the sanctuary portal, every micro-interaction is tuned for maximum fidelity.

## ✨ Key Experience Scenes

### 1. 🛩️ Scene 01: Stratospheric Sky Entry & Liquid Chrome Reveal
- **Volumetric Golden Hour Canyon**: High-altitude atmosphere with real-time mouse parallax translation.
- **Dynamic Telemetry HUD**: Live micro-fluctuations in altitude (12,400 m), ambient luminescence (142,000 lux), and quantum flux (1.42 Φ).
- **Chrome Typography & Light Sweeps**: Multi-stop metallic gradients with dynamic specular reflections and high-performance drop shadows.

### 2. 🎴 Scene 02: Zero-Gravity Floating Bento Orbit
- **Spatial Portals**: Multi-dimensional showcase highlighting stratospheric storm cells, bioluminescent glacial sanctuaries, and active aero carbon wings.
- **Interactive Portal Modals**: Deep-dive telemetry inspection with charge flux, vapor density, substrate purity, and laser optic metrics.
- **Category Matrix**: Real-time filtering across `ALL`, `NATURE`, and `HYPERCAR` categories.

### 3. 🏎️ Scene 03: The Valkyrie Aerodynamic Configurator
- **Live Wind Tunnel Particle Physics**: Dedicated HTML5 canvas simulation rendering 140+ individual streamlines with turbulence, velocity modulation, and aerodynamic flow lines.
- **Atmospheric Environments**:
  - 🌅 **Golden Sunset**: Photorealistic glass platform hovering above alpine waterfalls.
  - 🌌 **Midnight Aurora**: Glacial obsidian illuminated by emerald and violet ionization.
  - ⚡ **Alpine Storm**: High-contrast stratospheric thunderstorm reflections.
- **Bespoke Finishes**: Dynamic surface switching between *Liquid Titanium*, *Forged Carbon 3K Twill*, *Royal Champagne Gold*, and *Nebula Iridescent*.
- **X-Ray Diagnostic HUD**: Diagnostic blueprint overlay displaying vehicle architecture specs.
- **Interactive Telemetry Hotspots**: Deep exploration points for the Active Aero Wing, Hybrid V12 Powertrain (1,850 BHP), Magnetorheological Pushrod Suspension, and Carbon Monocoque.

### 4. 🪐 Scene 04: Anti-Gravity Sanctuary & Private Allocation
- **Inverted Physics Particle Engine**: Continuous upward-floating celestial embers and ambient water droplets floating toward deep space against a $-1.0G$ vector.
- **Liquid Metal Ripple CTA**: Hyper-gloss glass card with glowing aura and tactile sound triggers.
- **Private Allocation Portal**: Private reservation modal with bespoke verification flow.

## 🎧 Procedural Spatial Sound Engine

FII-INFINITY features a zero-asset procedural synthesizer built entirely on the **Web Audio API**:

- **Sub-Drone Core**: Dual harmonic oscillators at 43.65 Hz (F1) through resonant low-pass biquad filters simulating the hum of the V12 hybrid drive unit.
- **Pink Noise Wind Generator**: Filtered white/pink noise buffer producing ambient stratospheric airflow.
- **Metallic & Glass Harmonic Chimes**: Procedural sine and triangle envelopes triggering on interactive hover and portal clicks.
- **Bass Shockwave Pulses**: Exponential low-frequency decay sweeps upon activating major portals and allocation CTAs.
- **Toggle Control**: One-click audio master switch located directly in the persistent floating navigation dock.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18 or higher recommended) and `npm` installed.

```bash
node -v
npm -v
```

### Installation

1. Clone or navigate to the project directory:
   ```bash
   cd FII-INFINITY
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the Vite development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173` (or the URL displayed in your terminal).

### Production Build

Type-check and build the optimized production bundle:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## ⌨️ User Controls & Shortcuts

- **Mouse Movement**: Triggers 3D gyroscopic card tilt, cursor stardust trails, and panoramic depth parallax.
- **Audio Switch**: Toggle high-fidelity spatial ambient sound via the sound icon on the floating navigation dock.
- **Navigation Dock**: Click any numbered index (`01` to `04`) to smoothly fly to that sector of the realm.
- **Configurator Toggles**:
  - `Aero Simulation`: Toggle active aerodynamic wind streamlines.
  - `Atmosphere`: Switch between Golden Sunset, Midnight Aurora, and Alpine Storm.
  - `X-Ray Mode`: Toggle the structural telemetry and blueprint view.
  - `Chassis Finish`: Select bespoke material coatings (Titanium, Carbon, Gold, Nebula).
  - `Telemetry Hotspots`: Click the glowing targets on the vehicle to inspect subsystem diagnostics.
